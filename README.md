# 💰 ИИ-Сканер Вещей для Скупки (по Excel)

Этот скрипт позволяет сделать фото любой вещи через камеру телефона или компьютера. Искусственный интеллект (ИИ) распознает, что на картинке, переведет на русский язык и автоматически найдет цену скупки в вашей таблице Excel.

## 📥 Как скачать и запустить проект на компьютере:

1. Нажмите зеленую кнопку **Code** вверху страницы и выберите **Download ZIP**.
2. Распакуйте архив в любую папку.
3. Откройте терминал (командную строку) в этой папке и установите библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите скрипт командой:
   ```bash
   streamlit run app.py
   ```

## 📊 Как настроить цены:
Откройте файл `prices.xlsx` через обычный Excel. 
* В столбец **Предмет** пишите названия вещей (например: телефон, куртка, часы, ноутбук).
* В столбец **Цена** пишите вашу цену скупки.
